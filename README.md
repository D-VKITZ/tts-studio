# TTS Studio

TTS Studio — Text-to-Speech Studio PWA.

## Features

- Multi-voice text-to-speech synthesis
- SSML input support for advanced speech control
- Audio playback with speed and pitch controls
- Export to MP3 and WAV formats
- PWA for offline usage

## Tech Stack

React · Vite · Tailwind CSS · Web Speech API · PWA

## Quick Start

```bash
git clone https://github.com/D-VKITZ/tts-studio.git
cd tts-studio
npm install
npm run dev
```
